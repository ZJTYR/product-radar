# 海报中文字体

`NotoSansSC-Regular.otf` 为 Noto Sans 简体中文区域字体，来自 Noto 官方仓库，原文件未修改。用于服务端离线渲染热点海报，不依赖运行环境的系统字体或外部字体服务。

- 来源：https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf
- 上游提交：`f8d157532fbfaeda587e826d4cd5b21a49186f7c`
- 许可：SIL Open Font License 1.1，完整文本见 `OFL.txt`。字库包含上游作者与版权信息。
- 本字库覆盖简体中文、拉丁字母、数字和常用标点。海报将 emoji、控制字符和未覆盖的生僻文字替换为可显示的占位字符，不依赖系统字体回退。
